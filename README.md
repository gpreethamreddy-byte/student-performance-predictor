# 🎓 Student Performance Predictor

A beginner-friendly Machine Learning project that predicts student performance based on study hours, attendance, and previous marks.

## 📌 Features

- Takes student details as input
- Uses a Decision Tree Classifier
- Predicts student performance
- Provides a simple Streamlit web interface
- Handles user input with validation

## 🛠️ Technologies Used

- Python
- Pandas
- Scikit-learn
- Streamlit

## 📊 Input Features

The model uses:

- Study hours per day
- Attendance percentage
- Previous marks

## 🤖 Machine Learning Model

Decision Tree Classifier
